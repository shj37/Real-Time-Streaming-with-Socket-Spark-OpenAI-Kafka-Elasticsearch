# Real-Time Streaming with TCP/IP Socket, Spark, OpenAI, Kafka & Elasticsearch

![project overview](https://miro.medium.com/v2/resize:fit:1100/format:webp/1*qjSyLr5ZNNTrlsaMl_ScqQ.jpeg)

This repository hosts a real-time data streaming pipeline processing 7 million Yelp reviews. It’s built with a robust tech stack for ingestion, processing, enrichment, streaming, and querying.

## Features
- Ingestion: TCP/IP Socket for efficient data streaming.
- Processing: Apache Spark with OpenAI LLM for sentiment analysis.
- Streaming: Apache Kafka for reliable data flow.
- Search: Elasticsearch for real-time indexing and querying.

## Tech Stack
- Python
- Apache Spark
- OpenAI API
- Apache Kafka
- Elasticsearch
- TCP/IP Socket
- Docker
